## Hello

Thank you for trying d77void Mango edition.

This ISO uses MangoWC as the window manager.

To install use Calamares from the menu.

## Keybinds

alt + return -> terminal

alt + space -> app launcher

alt + n -> menu2

alt + r -> d77run

alt + q -> close window

alt + z -> scratchpad

alt + tab -> toggle overview

alt + f -> fullscreen

alt + backslash -> toggle floating

super + left / right -> switch workspace

super + t -> lock screen

super + x -> powermenu

super + m -> quit mango

## Idle

After 5 minutes without input the screen locks (swaylock), after 10 it
turns off, and it always locks before suspending (swayidle, started from
config.conf).

## Mango tweaks

To alter the autostart programs, add/swap keybinds and keyboard layout configure ~/.config/mango/config.conf ; the file is self explanatory and with several examples already configured.

Have fun!
