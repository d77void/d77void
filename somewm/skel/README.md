## Keybinds

super + return -> terminal

super + a -> app launcher (fuzzel)

super + z -> powermenu

super + alt + l -> lock screen

super + c -> toggle calendar

super + s -> display keybinds

super + w -> menu (this is the main awesome menu)

super + r -> run

super + q -> close window

super + f -> toggle fullscreen

super + t -> toggle keep on top

super + 1-9 -> switch to tag

super + shift + 1-9 -> move window to tag

super + space -> next layout

super + ctrl + r -> reload config

super + shift + q -> quit
